A free, plain, photo-first blog theme for nail and beauty sites.

== Description ==

Nail Niche is a simple, free blog theme built around large photos. It is made for nail and beauty blogs: posts of nail ideas, care tips and salon guides, written in the blogger's own voice.

* Seven home page designs to pick from in Appearance → Customize → Home design: Classic, Magazine, Pinterest board, Personal blog, Color shop (color swatches), Seasonal (a banner for the season or holiday, picked by date) and Minimal list (titles by month).
* A Pinterest Save button on every photo in a post (it saves that photo with the post's link).
* Comments under posts, with replies.
* Posts with a large featured photo (not repeated when the same photo is already at the top of the post).
* An About box in the sidebar and under posts: photo, heading and text, set in Appearance → Customize → About box.
* Theme options (Appearance → Customize → Theme options): accent colour, the guides category and its heading, and the colors category for the Color shop design.
* Main menu and footer menu (Appearance → Menus) and your own logo (Appearance → Customize → Site Identity).
* Two sidebar widget areas (Appearance → Widgets): "Home page sidebar" and "Post and archive sidebar". Add any block, such as Custom HTML, Image or Latest Posts. They show under the built-in sidebar sections.
* No built-in ad spaces: use an ad plugin such as Ad Inserter.
* Affiliate links are marked the way Google asks (rel="sponsored nofollow") and open in a new tab. A link counts as affiliate when it points to a known affiliate network or has the class "affiliate".
* Staging and local copies of a site (staging addresses, .local, localhost, or a WordPress environment type of staging/development/local) are kept out of search engines.
* One-click demo content (Appearance → Demo content): posts with photos, guides, pages, menus and settings, so a new site looks like the preview. Remove it again with one click.
* Updates itself from GitHub releases: new versions show under Dashboard → Updates.
* One self-hosted font (Libre Franklin), no outside requests for fonts.
* Works on phones: the sidebar moves under the content on small screens.

== Installation ==

1. In WordPress, go to Appearance → Themes → Add New → Upload Theme.
2. Choose nail-niche.zip and click Install Now, then Activate.
3. Optional: go to Appearance → Demo content and click Import demo content to make the site look like the preview.
4. Set your logo, the About box and Theme options in Appearance → Customize.
5. Add your menus in Appearance → Menus.
6. Optional: add blocks to the sidebars in Appearance → Widgets.

== Frequently Asked Questions ==

= Does the theme need a page builder? =

No. It works with the normal WordPress editor.

= Where do I put my ad code? =

Use an ad plugin such as Ad Inserter. For an ad in the sidebar, you can also add a Custom HTML block to a sidebar in Appearance → Widgets.
